# ATS CV Domain

Preserve canonical CV JSON as the source for analysis, tailoring, library storage, and export. Keep exported PDF and DOCX text selectable and ATS-extractable. Do not invent experience, credentials, employers, dates, metrics, or skills during tailoring.

Respect scanned versus text-based PDF behavior, vision-only handling for image-based uploads, template mappings, contact and section slots, and deterministic renderers. Validate that changes preserve factual content and do not silently drop sections.
