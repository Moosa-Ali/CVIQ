# Project Management

Start with the user outcome, not a list of files. Separate scope, non-goals, assumptions, dependencies, risks, and acceptance criteria.

Every task should state:
- User-visible result.
- Owning agent and file scope.
- Preconditions and dependencies.
- Test or browser evidence required.
- Completion and rollback conditions.

Do not treat an implementation plan as proof that the feature works.
