# UX Research

Trace the user journey from upload and job description through analysis, tailoring, template selection, library use, and export. Look for unclear next actions, hidden state, lost work, weak feedback, confusing terms, and unrecoverable errors.

Recommendations must be specific to the existing product and expressed as observable behavior that QA can verify.
