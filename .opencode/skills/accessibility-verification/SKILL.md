# Accessibility Verification

Use keyboard-only navigation first. Check landmarks, heading order, labels, names, descriptions, status and error announcements, focus trapping, focus restoration, contrast, touch targets, zoom, reflow, reduced motion, and mobile layout.

Primary CV upload, analysis, tailoring, template, and export workflows must be keyboard-completable. Report the affected control or selector, reproduction steps, user impact, severity, and suggested direction without editing source.
