# UI Design System

Inspect the existing visual language before changing it. Use a deliberate hierarchy, consistent spacing, clear focus states, responsive layouts, and purposeful empty/error states. Do not produce generic dashboard styling or decorative elements that compete with CV content.

Verify desktop, mobile, zoom/reflow, long labels, long CV content, loading, errors, and reduced-motion behavior. Keep CV export templates selectable and ATS-extractable.
